## 📌 About the Project

**Loomé** is a clean fashion/product landing page designed around a premium organic cotton collection.

The page focuses on:

* Minimal and modern UI
* Product presentation
* Typography
* Flexbox layouts
* Positioning
* Image galleries
* Product pricing and ratings
* Feature highlights
* Clean navigation

The project was created to strengthen my understanding of **HTML structure and CSS layout techniques**.

## 🎨 Design

The project uses a warm, minimal color palette with:

* Off-white background
* Green accents
* Rounded product cards
* Circular action button
* Minimal typography
* Large hero typography

## The main page uses **Flexbox** for the header, hero section, gallery, and footer layouts.
