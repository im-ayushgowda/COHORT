A structured JavaScript practice website designed for building programming fundamentals, logic, and problem-solving skills through progressive practice questions.

## 📚 About the Project

This project contains JavaScript practice questions organized into phases and sheets. The content is designed to progress from basic JavaScript concepts to more advanced logic-building and real-world programming practice.

The repository is intentionally structured so new practice sheets and questions can be added over time without changing the purpose of the project.

### Current Practice Areas

- JavaScript fundamentals
- Variables and data types
- Type conversion and operators
- Strings and numbers
- Conditionals and logical thinking
- Functions
- Arrays and array methods
- Objects and object methods
- Functional programming concepts
- Debugging practice
- Scenario-based problems
- Interview-oriented questions
- Real-world logic and mini-project challenges

## ✨ Features

### Interactive Questions
Questions can be expanded and explored directly on the website.

### Practice Console
Each question includes a small JavaScript console where you can write, run, and test your own solution.

### Complete Solutions
Solutions are available through a dropdown so you can attempt the problem first and use the solution as a reference when needed.

### Local Answer Saving
Practice answers are automatically saved in the browser using `localStorage`.

This means:

- Your code remains after refreshing the page.
- Your code remains when you reopen the website in the same browser.
- Each question has its own saved answer.
- Clearing a question removes its saved answer.
- Answers are stored locally in the browser and are not uploaded to the repository.

> Note: local saved answers are browser/device-specific. They are not synchronized between different browsers or computers.

### Search & Navigation
Use the search bar and sheet/section navigation to quickly find specific questions and topics.

## 🚀 How to Use

1. Open the live website or run the project locally.
2. Select a topic or sheet.
3. Read the question carefully.
4. Write your own solution in the practice console.
5. Click **Run** to test your code.
6. Check the output.
7. Open **Complete Solution** only when you need a reference.
8. Continue to the next question.

## 💻 Run Locally

